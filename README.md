# 电商用户行为运营分析（淘宝用户行为日志）

> 数据运营方向求职作品集项目
> 一句话：基于淘宝 9 天全链路行为日志（浏览→加购→购买），用 SQL+Python 完成清洗、指标建模与运营看板搭建，从流量、转化、分层、时段、类目五个维度定位运营卡点，并对留存口径做数据质量诊断，对标行业基准输出可落地运营策略。

## 二、抽样口径（重要）

**方法**：按用户等概率简单随机抽样（抽"人"不抽"行"）。对去重后的全部 user_id 排序后，`random.seed(42)` 固定种子 + shuffle 取前 10%（精确比例，非 `random()<0.1` 近似）。

| 指标 | 实测值 |
|---|---|
| 全量用户数 | **987,994** |
| 抽样用户数 | **98,799** |
| 实际抽样占比 | **10.0000%** |
| 抽样行数 | **10,023,087**（不含表头） |

**为什么按用户抽**：若按行抽（`WHERE RAND()`），行为多的用户更容易被抽中，且会拆散单个用户的行为链，漏斗/留存全失真。按用户抽保持行为链完整，比率类指标（转化率/留存率）在随机抽样下无偏。

**可复现**：固定种子 42，抽样集 `data/UserBehavior_sample.csv` 生成后冻结不重抽，任何时间重跑得到相同用户与数字。README 记录种子 + 实际占比，数字可溯源。

**数据冻结说明**：导入 MySQL 的表为 `user_behavior_sample`（10,023,087 行，数据行，不含表头），后续所有 SQL 均基于抽样集口径。

## 三、数据清洗（01）

### 3.1 分析窗口

数据集官方口径为 **2017-11-25 ~ 2017-12-03 共 9 天**。原始文件在该窗口外还有 5,569 行记录：既有紧邻窗口的日期（2017-11-01 ~ 11-24、2017-12-04 ~ 12-14），也有明显离群的时间戳（1979-03-16、2017-04、2018、2025-11-03）。为保持与数据集官方口径一致，并避免窗口外记录把用户"首次行为日"错算到 11-25，一律裁切到 9 天窗口内。

### 3.2 剔除记录构成（实测 5,569 行）

| 性质 | 行数 |
|---|---|
| 时间戳为负 | 14 |
| 早于 2017-11-07（含 1979、2017-04 等离群日期） | 227 |
| 2017-11-07 ~ 11-24（窗口前） | 5,120 |
| 2017-12-04（窗口后当天） | 116 |
| 2017-12-05 及以后（含 2018、2025 离群日期） | 92 |
| 非法行为类型 | 0 |
| 非法类目（category_id ≤ 0） | 0 |
| **合计** | **5,569** |

### 3.3 清洗结果

- 清洗后明细：**10,017,518 行**，去重用户 **98,798**，日期范围恰为 9 天
- 行为类型分布（清洗后）：

| 行为 | 行为数 | 去重用户数 |
|---|---|---|
| 浏览(pv) | 8,976,117 | 98,435 |
| 加购(cart) | 552,395 | 73,831 |
| 收藏(fav) | 288,176 | 39,038 |
| 购买(buy) | 200,830 | 67,319 |

## 四、核心指标口径

| 指标 | 定义 |
|---|---|
| PV / UV | `pv` 行为总次数 / 去重 `user_id` 数 |
| **序列漏斗三环节** | 以各行为的**最早发生时间**为准，要求时序依次发生：`t_pv < t_cart < t_buy`。第 N 环节成立的前提是第 N-1 环节已成立且发生在它之前 |
| 浏览→加购 转化率 | 加购环节用户数 / 浏览用户数 |
| 加购→购买 转化率 | 购买环节用户数 / 加购环节用户数 |
| 全链路转化率 | 购买环节用户数 / 浏览用户数 |
| 环节流失率 | 1 − 该环节转化率 |
| 用户付费率 | 购买用户数 / 总用户数（**用户级**口径） |
| 事件级 PV→购买转化率 | 购买次数 / PV 次数（**事件级**口径，可与行业页面级指标对比） |
| **R 档（近度，5 档评分设计）** | 最近一次**购买**距分析末日（2017-12-03）天数：≤1天=5档 ≤3天=4档 ≤7天=3档 ≤15天=2档 >15天=1档 |
| **F 档（频次）** | 9 天内购买次数：≥5次=5档 3-4次=4档 2次=3档 1次=2档 0次=1档 |
| **高价值用户** | R≥4 且 F≥4，即"最近 3 天内购买过 + 9 天内购买≥3 次" |
| 高价值用户贡献度 | 高价值用户购买次数 / 全体用户购买次数（数据集无金额，以购买次数近似） |

**漏斗为什么必须按序列算**：若只统计"有多少人分别做过 pv / cart / buy"，得到的是**集合并集**——有 14,206 名用户从未加购却直接购买了，他们会被错误地计入"浏览→加购"的流失。只有要求时序依次发生，漏斗才反映路径上的真实流失。

**R 档观测范围**：数据窗口仅 9 天，R 最大到 8，故 15 天档（1 档）窗口内无用户，实际观测到 5/4/3/2 四档。这是窗口长度的客观限制，已在 03_2 明细中如实呈现。

## 五、分析结论（每个数字可在 `results/` 对应 CSV 溯源）

### 5.1 转化漏斗（results/02*.csv）

| 环节 | 用户数 | 转化率 | 流失率 |
|---|---|---|---|
| 浏览 → 加购 | 98,435 → 67,083 | **68.15%** | 31.85% |
| 加购 → 购买 | 67,083 → 30,925 | **46.10%** | **53.90%** |
| 全链路（浏览→购买） | — | **31.42%** | — |

**结论**：**"加购→购买"是最大流失卡点**——31,352 名用户在加购前流失，但有 **36,158 名用户加购后没有购买**，流失率 53.90%（远高于浏览→加购的 31.85%）。运营重点应是购物车挽回：加购未购用户的催付提醒、限时优惠、库存/价格提醒。浏览→加购仍有 31.85% 流失，可用详情页加购引导承接。

### 5.2 收藏作为平行信号（results/02_3.csv）

| 类型 | 用户数 | 购买转化率 |
|---|---|---|
| 收藏用户 | 39,038 | **71.19%** |
| 未收藏用户 | 59,760 | **66.15%** |

**结论**：收藏用户的购买转化率比未收藏用户高约 **5 个百分点**，收藏是购买意向的正向信号。漏斗主路径用加购（时序上离付款更近），收藏单独做对比分析。

### 5.3 RF 用户分层（results/03.csv，二八法则验证）

| 分层 | 用户数 | 用户占比 | 购买贡献占比 |
|---|---|---|---|
| **高价值**（R≥4且F≥4） | 23,591 | **35.04%** | **62.42%** |
| 潜力（R≥3且F≥3） | 19,951 | 29.64% | 25.17% |
| 普通 | 23,777 | 35.32% | 12.42% |

**结论**：**35.04% 的高价值用户贡献了 62.42% 的购买行为**，验证二八法则。对高价值用户做专属召回（复购推送、会员权益）ROI 最高。

R 档位分布（results/03_2.csv，与 03.csv 同一 R 口径）：5档 30,214 / 4档 15,688 / 3档 18,520 / 2档 2,897，无 1 档。

### 5.4 时段分析（results/05*.csv）

- **24 小时活跃**：晚 **19-22 点**为高峰，四小时合计占全天 PV 的 **30.14%**；峰值在 **21 点（PV 758,098 / 66,257 用户）**，凌晨 4-5 点最冷清
- **一周分布**：窗口 9 天里周六/周日各出现 2 次、周一至周五各出现 1 次，因此必须按**日均**比较。按日均，周六 1,081,428 / 周日 1,088,878，工作日日均 927,101，约 **1.17 倍**；进一步剔除窗口末尾两个活跃度突变日（12-02 / 12-03，见 5.5）后，周六（11-25）935,165 / 周日（11-26）952,609 与工作日日均 927,101 **基本无差异**
- **结论**：**本数据集不支持"周末更活跃"的结论**，真实可用的是"晚间 19-22 点"这个日内规律
- **运营启示**：活动排期与推送集中晚 19-22 点，触达效率最高

### 5.5 留存分析（results/04.csv）—— 数据质量诊断

以用户首次行为日为注册日（数据集无注册字段），计算次日/3日/7日留存。窗口外的档位输出空值（不可观测），不输出 0。

| 注册日 | 注册用户数 | 次日留存 | 3日留存 | 7日留存 |
|---|---|---|---|---|
| 11-25（首日） | 70,625 | 78.91% | 75.77% | **98.53%** |
| 11-26 | 15,733 | 65.63% | 66.29% | 97.25% |
| 11-27 | 6,368 | 61.56% | 63.96% | 窗口外 |
| 11-28 | 3,222 | 61.42% | 66.33% | 窗口外 |
| 11-29 | 1,830 | 68.14% | **96.28%** | 窗口外 |
| 11-30 | 998 | **93.99%** | 94.69% | 窗口外 |
| 12-01 | 20 | 90.00% | 窗口外 | 窗口外 |
| 12-02 | 2 | 100.00% | 窗口外 | 窗口外 |

**诊断结论：本数据集的 cohort 留存不可解释为真实留存，不产出留存业务结论。**

证据链：

1. **留存曲线不是递减的**，而是随 calendar day 跳变。7 日留存高达 98.53%（> 次日留存 78.91%）、3 日留存 96.28%、次日留存 93.99% 这些高值，**只在「注册日 + N = 12-02 或 12-03」时出现**。
2. 原因：**数据集末尾两天接近"全员活跃"**。12-02 有 97,021 名用户活跃，占全部 98,798 用户的 **98.2%**；12-03 为 96,676（97.9%）。而在**全量 3.67GB 原始数据**上同样成立（12-02 = 941,709 人 / 95.32%），因此这不是抽样或代码问题，是数据集本身的特性。
3. **99.87% 的用户其末次活跃落在窗口最后两天**，且只有 2 名用户首次出现在最后两天——说明该数据集的用户抽样框锚定在窗口末尾，而不是在 9 天里均匀展开。
4. 因此 11-25 cohort 的 7 日留存 98.53%，含义是"这批用户在窗口最后一天几乎都被观测到活跃"，而非"用户回来了"。

**这一节的价值在于**：识别出公开数据集的时间截断偏差，并判定某一模块在当前数据上不可用——而不是把 98.53% 当成留存成绩写进结论。

### 5.6 类目分析（results/06*.csv）

> PV转购买率为**事件级**口径（购买次数 / PV次数），与 5.1 的用户级漏斗口径不同，不可互相换算。

- **高曝光低转化类目**（PV ≥ 10 万）：类目 2355072（317,081 PV）转化率仅 **0.389%**；3607361（298,508 PV）**0.429%**；4756105（447,776 PV，头部曝光量最大）**0.625%**
- **高转化类目**：类目 2885642（95,124 PV）转化 **3.298%**；2735466（110,211 PV）**3.024%**；2640118（71,849 PV）**2.502%**
- **运营启示**：头部曝光类目转化率显著低于整体，存在详情页/定价/流量分配优化空间；高转化类目多为曝光量中等的类目，值得加流量

## 六、运营建议

1. **购物车挽回优先**：加购→购买流失 53.90%（36,158 人加购后未购买），这是全链路最大卡点。建议加购未购用户的催付提醒、限时优惠券、降价/库存提醒
2. **详情页加购引导**：浏览→加购仍有 31.85% 流失，建议优化加购入口与商品卖点呈现
3. **高价值用户专属召回**：35.04% 用户贡献 62.42% 购买，做复购推送 + 会员权益，ROI 最高
4. **黄金时段排期**：晚 19-22 点占全天 PV 的 30.14%，促销与推送集中此时段
5. **收藏信号利用**：收藏用户转化率高 5 个百分点，对"已收藏未购买"用户做定向促购
6. **类目流量再平衡**：高曝光低转化类目（2355072 / 3607361 / 4756105）优化承接，高转化类目（2885642 / 2735466）加流量

## 七、行业基准对比

> 行业数据为 2024 年，本项目数据集为 2017 年，时间与口径存在差异。对比时给区间而非单点，重点看相对位置。

- **QuestMobile《2024年移动互联网春季报告》**：移动购物行业月活跃用户 **10.73 亿**（2024年3月，同比增长 5.7%），全网中高消费意愿用户占比突破 75%（来源：四川经济日报转载，访问日期 2026-08-10）
- **商务部电子商务司《2024年我国电子商务发展情况》**：2024 全年网上零售额同比增长 **7.2%**，实物网零拉动社零增长 1.7 个百分点（来源：新浪财经转载，访问日期 2026-08-10）
- **艾瑞咨询《2024年中国电商市场研究报告》**：报告页实测确认存在（report.iresearch.cn/report/202409/4388.shtml，2024/9/30 发布）；免费简介不含具体转化率数字，仅作研究参考


**本项目与行业的位置**：

| 本项目指标 | 数值 | 口径 | 与行业对比 |
|---|---|---|---|
| 事件级 PV→购买转化率 | **2.237%**（200,830 / 8,976,117） | 事件级（次数比次数） | **可直接对标**行业页面级 2-5%，处于区间内 |
| 全链路转化率 | **31.42%** | 用户级 | 与行业页面级指标**不可直接比较** |
| 用户付费率 | **68.14%**（67,319 / 98,798） | 用户级 | 同上 |

**为什么用户级不能对标行业**：本数据集只包含"产生过行为"的用户，已天然筛掉纯浏览退出的访客，用户级指标必然偏高。真正可比的是事件级的 2.237%。

## 八、局限与诚实边界

| 局限 | 说明 |
|---|---|
| 数据时效 | 2017 年 9 天窗口的公开数据集，非实时数据 |
| 无金额字段 | 高价值用户贡献度以**购买次数**近似，非 GMV |
| 留存不可用 | 数据集末尾两天接近全员活跃（12-02 = 98.2%），抽样框锚定窗口末尾，cohort 留存不产出业务结论（见 5.5） |
| 星期维度受限 | 9 天窗口内各星期出现天数不等（周末 2 天、工作日 1 天），且末尾两天活跃度突变，只能按日均比较且需剔除异常日 |
| R 档区分度 | 窗口仅 9 天，R 最大到 8，1 档无用户；高价值分层实际主要由 F（购买频次）驱动 |
| 抽样口径 | 全部数字为 10% 抽样口径，总量类指标按比例外推需注意 |
| 注册定义 | 无注册字段，以"首次行为日"近似 |
| 行业对比 | 行业数据 2024 年 vs 本项目 2017 年，时间口径差异，给区间看相对位置 |
