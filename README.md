# 电商用户行为运营分析（淘宝用户行为日志）

> 数据运营方向求职作品集项目
> 一句话：基于淘宝 9 天全链路行为日志（浏览→收藏→加购→购买），用 SQL+Python 完成清洗、指标建模与运营看板搭建，从流量、转化、分层、时段、留存五个维度定位运营卡点，对标行业基准，输出可落地运营策略。

## 二、抽样口径（重要）

**方法**：按用户等概率简单随机抽样（抽"人"不抽"行"）。对去重后的全部 user_id 排序后，`random.seed(42)` 固定种子 + shuffle 取前 10%（精确比例，非 `random()<0.1` 近似）。

| 指标 | 实测值 |
|---|---|
| 全量用户数 | **987,994** |
| 抽样用户数 | **98,799** |
| 实际抽样占比 | **10.0000%** |
| 抽样行数 | **10,023,087**（不含表头） |

**为什么按用户抽**：若按行抽（`WHERE RAND()`），行为多的用户更容易被抽中，且会拆散单个用户的行为链，漏斗/留存全失真。按用户抽保持行为链完整，比率类指标（转化率/留存率）在随机抽样下无偏。

**可复现**：固定种子 42，抽样集 `data/UserBehavior_sample.csv` 生成后冻结不重抽，任何时间重跑得到相同用户与数字。README 记录种子 + 实际占比，数字可溯源。

**数据冻结说明**：导入 MySQL 的表为 `user_behavior_sample`（10,023,088 行），后续所有 SQL 均基于抽样集口径。

## 三、数据清洗（01）

- 抽样集存在 **5,570 行**时间戳超出数据窗口（负值/1970年代/2015等异常值），会污染留存"注册日"与时段分布，**全部剔除**
- 清洗后明细：**10,017,518 行**，去重用户 **98,798**，日期范围恰为 9 天
- 行为类型分布（清洗后）：

| 行为 | 行为数 | 去重用户数 |
|---|---|---|
| 浏览(pv) | 8,976,117 | 98,435 |
| 加购(cart) | 552,395 | 73,831 |
| 收藏(fav) | 288,176 | 39,038 |
| 购买(buy) | 200,830 | 67,319 |

## 四、核心指标口径

| 指标 | 定义 |
|---|---|
| PV / UV | `pv` 行为总次数 / 去重 `user_id` 数 |
| 浏览→加购 转化率 | 加购用户数 / 浏览用户数 |
| 加购→购买 转化率 | 购买用户数 / 加购用户数 |
| 全链路转化率 | 购买用户数 / 浏览用户数 |
| 环节流失率 | 1 − 该环节转化率 |
| 用户付费率 | 购买用户数 / 总用户数 |
| **R 档（近度，5 档设计）** | 最近购买距分析末日（2017-12-03）天数：≤1天=5档 ≤3天=4档 ≤7天=3档 ≤15天=2档 >15天=1档 |
| **F 档（频次）** | 9 天内购买次数：≥5次=5档 3-4次=4档 2次=3档 1次=2档 0次=1档 |
| **高价值用户** | R≥4 且 F≥4，即"最近 3 天内活跃 + 9 天内购买≥3 次" |
| 高价值用户贡献度 | 高价值用户购买次数 / 全体用户购买次数（数据集无金额，以购买次数近似，README 标注） |

**R 档双口径说明**：R 采用 5 档评分设计（行业通用粒度），分界 1/3/7/15 天对应日/周/双周/月。因数据窗口仅 9 天，R 最大到 9，15 天档（档1）窗口内无用户，**实际观测到 5/4/3/2 四档**。这是"设计口径"与"数据口径"的差异，不是模型错误。

## 五、分析结论（每个数字可在 `results/` 对应 CSV 溯源）

### 5.1 转化漏斗（results/02*.csv）

| 环节 | 用户数 | 转化率 | 流失率 |
|---|---|---|---|
| 浏览 → 加购 | 98,435 → 73,831 | **75.00%** | **25.00%** |
| 加购 → 购买 | 73,831 → 67,319 | **91.18%** | 8.82% |
| 全链路（浏览→购买） | — | **68.39%** | — |

**结论**：**"浏览→加购"是最大流失卡点**（流失 25%），加购用户几乎都购买（91.18%）。运营重点是提高从浏览到加购的转化——优化商品详情页加购引导、限时优惠提示。

### 5.2 收藏作为平行信号（results/02_3.csv）

| 类型 | 用户数 | 购买转化率 |
|---|---|---|
| 收藏用户 | 39,038 | **71.19%** |
| 未收藏用户 | 59,760 | **66.15%** |

**结论**：收藏用户的购买转化率比未收藏用户高约 **5 个百分点**，收藏是强购买意向信号。漏斗主路径用加购（意向更强），收藏单独做对比分析。

### 5.3 RF 用户分层（results/03.csv，二八法则验证）

| 分层 | 用户数 | 用户占比 | 购买贡献占比 |
|---|---|---|---|
| **高价值**（R≥4且F≥4） | 28,563 | 42.43% | **72.89%** |
| 潜力（R≥3且F≥3） | 15,698 | 23.32% | 15.63% |
| 普通 | 23,058 | 34.25% | 11.48% |

**结论**：**42.43% 的高价值用户贡献了 72.89% 的购买行为**，验证二八法则。对高价值用户做专属召回（复购推送、会员权益）ROI 最高。

R 档位分布（results/03_2.csv）：5档 30,214 / 4档 15,688 / 3档 18,520 / 2档 2,897，**无 1 档（>15天）**，符合"5档设计/窗口内观测4档"。

### 5.4 时段分析（results/05*.csv）

- **24 小时活跃**：晚 **19-22 点**为高峰（21点最活跃，PV 758,667 / 66,379 用户），凌晨 4-5 点最冷清
- **一周分布**：**周末（周六 216 万、周日 218 万 PV）约为工作日（约 90 万）的 2.4 倍**
- **运营启示**：活动排期与推送集中晚 19-22 点 + 周末，触达效率最高

### 5.5 留存分析（results/04.csv）

以用户首次行为日为注册日（数据集无注册字段）：

| 注册日 | 注册用户数 | 次日留存 | 3日留存 | 7日留存 |
|---|---|---|---|---|
| 11-25（首日） | 70,625 | 78.91% | 75.77% | 98.53% |
| 11-26 | 15,733 | 65.63% | 66.29% | 97.25% |
| 11-27 | 6,368 | 61.56% | 63.96% | 窗口外(0) |
| 11-28 | 3,222 | 61.42% | 66.33% | 窗口外(0) |

**结论**：次日留存 61~79%，3日留存 64~76%。11-25 首日注册用户留存最高（首日存在拉新活动效应），后续批次回落至 60%+。

**⚠️ 局限（面试主动说）**：数据仅 9 天，11-27 之后注册的用户 7 日留存超出窗口观测不到；7 日留存（98.53%）偏高是因该数据集用户活跃度高 + "首次行为=注册日"会把持续活跃的老用户计入新注册，样本偏小，**重点看次日/3日趋势**。

### 5.6 类目分析（results/06*.csv）

- **高曝光低转化类目**：类目 4756105 有 447,776 次浏览但 PV 转购买率仅 **0.625%**；类目 3607361（298,508 PV）转化率 0.429%
- **高转化低曝光类目**：类目 2735466（110,211 PV）转化率 **3.02%**，类目 2885642 达 3.30%
- **运营启示**：头部曝光类目转化率反而低，存在详情页/定价/流量分配优化空间；高转化小众类目值得加流量

---

## 六、运营建议（内外结合）

1. **优化加购引导**：浏览→加购流失 25% 是最大卡点，建议详情页加购引导 + 限时优惠提示
2. **高价值用户专属召回**：42.43% 用户贡献 72.89% 购买，做复购推送 + 会员权益，ROI 最高
3. **黄金时段排期**：晚 19-22 点 + 周末双高峰，促销和推送集中此时段
4. **收藏信号利用**：收藏用户转化率高 5 个百分点，对收藏未购用户做定向促购
5. **类目流量再平衡**：高曝光低转化类目优化承接，高转化低曝光类目加流量

## 七、行业基准对比

> 行业数据为 2024 年，本项目数据集为 2017 年，时间与口径存在差异。对比时给区间而非单点，重点看相对位置。

- **QuestMobile《2024年移动互联网春季报告》**：移动购物行业月活跃用户 **10.73 亿**（2024年3月，同比增长 5.7%），全网中高消费意愿用户占比突破 75%（来源：四川经济日报转载，访问日期 2026-08-10）
- **商务部电子商务司《2024年我国电子商务发展情况》**：2024 全年网上零售额同比增长 **7.2%**，实物网零拉动社零增长 1.7 个百分点（来源：新浪财经转载，访问日期 2026-08-10）
- **艾瑞咨询《2024年中国电商市场研究报告》**：报告页实测确认存在（report.iresearch.cn/report/202409/4388.shtml，2024/9/30 发布）；免费简介不含具体转化率数字，仅作研究参考


**本项目与行业的位置**：本数据集的用户付费率约 68%（购买用户/总用户），全链路转化率 68.39%，处于电商行业正常区间偏高水平（行业移动购物用户规模持续增长、网上零售额稳健增长的大背景）。

## 八、局限与诚实边界

| 局限 | 说明 |
|---|---|
| 数据时效 | 2017 年 9 天窗口的公开数据集，非实时数据 |
| 无金额字段 | 高价值用户贡献度以**购买次数**近似，非 GMV |
| 留存窗口 | 仅 9 天，7 日留存样本偏小，11-27 后注册用户观测不到 7 日 |
| 抽样口径 | 全部数字为 10% 抽样口径，总量类指标按比例外推需注意 |
| 注册定义 | 无注册字段，以"首次行为日"近似 |
| 行业对比 | 行业数据 2024 年 vs 本项目 2017 年，时间口径差异，给区间看相对位置 |
